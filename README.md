# Re-Leaf India
Website for creating awareness among people about afforestation and its significance with an interactive site for the users to know about their state. 

## Features
1. Lets the user to know about their state via map
2. Each state's map highlights the forest cover, afforestation status and its        district names.

## Home page 
Labels the role of the forests in our country, the schemes offered by our country to facilitate the afforestation journey.

## Know your state
Exclusively meant for the users to select their state and view the state's progress and condition in the afforestation journey.

## Tech used
- html,css,javascript
- geojson data
- leaflet.js

## Data sources
- Forest Survey of India (FSI)
- Survey Of India
